# ⚡ WHEN SOMETHING HAPPENS: 8 PLAYBOOKS
A **playbook** = a step-by-step recipe for a surprise. Files are in `playbooks/`.
To use one, type `/playbook` followed by what happened, e.g. `/playbook we got a 1-star review on Google saying the wait was too long`.

| Event | Trigger | Who handles it | Needs you? |
|---|---|---|---|
| Search demand spikes | keyword searches +50% | Search + Content | only for paid boost |
| Competitor drops a promo | new competitor offer | Market radar + Content | yes, if we counter with an offer |
| One-star review lands | 1–3★ review | Reviews | **always** |
| Content calendar looks thin | < 5 posts in next 7 days | Content + Creative | no |
| A post goes viral | 3× normal engagement | Publishing + Leads | only for paid boost |
| Ranking drops a page | −10 positions | Search + Content | for site code fixes |
| Ad creative fatigues | click rate −30% | Creative + Results | **always** (ads) |
| DM or lead at 11pm | out-of-hours message | Leads | morning hand-off for hot leads |
